# 116. Restart-per-season packs flatten onto the concatenated axis; Organize slices by AniList id

**Location:** `nyaa/nyaa.go` — `PackFileRange`, `flattenRestartPackGroups`, `FilesInPackWindow`; `files/librarian.go` — `Organize` / `OrganizeRequest.SeriesOffset`; `files/filemanager.go` — `EpisodeStruct.SeriesOffset` / `AnimeSeason`; `daemon/jobs.go` — `organizeTorrent` groups by `AnimeID`; `daemon/episodes.go` / `coverage.go` persist the offset at download and adopt. Pinned by `TestPackFileRange_RestartSeasonGroupsFlattenOntoConcatenatedAxis`, `TestOrganizeRestartPackRoutesSeasonFilesToThisEntry`, `TestCoverageOwnership_KaguyaRestartPackCoversS2`, `TestOrganizeRestartPackHardlinksMushokuExtras`.

**What it looks like:** an EMBER Kaguya S1+S2 pack (`nyaa.si/view/1355132`) stores `BatchStart/End` 1–24 under S1, not 1–12. Completing S1 with S2 still absent from watching leaves a span larger than S1's total, so [#74](074-the-pack-exclusion-guards-unit-is-the-torrents.md) still sees unclaimed content; the torrent is kept only while a claimed season is in watching ([#117](117-off-list-bypasses-the-unclaimed-pack-guard.md)). When S2 enters watching, `findCoveringPack` adopts the hash already on disk ([#78](078-a-torrents-unit-of-ownership-is-coverage-on-the.md)). `Organize` hardlinks S01 files into the S1 folder and S02 files into the S2 folder — one folder per AniList entry ([#45](045-one-library-folder-per-anilist-entry-the-season.md)).

**Why it's right:** [#84](084-a-pack-without-a-range-in-its-name-gets-its.md)'s min-max of restart numbering made S1 claim the whole pack (span 12 of 12) and delete it before S2 was watching. Continuous 1–24 packs already survived that pass. Flattening overlapping season groups (S01 1–12 + S02 1–12 → 1–24) reuses `#74`/`#78` with no new ownership field. Future AniList ids are **not** stored at S1 download: the PREQUEL walk has no sequels ([#71](071-anilist-has-no-franchise-id-the-prequel-chain-is.md)); S2 resolves via `Series.Key` + offset when it is requested.

**How groups are keyed.** Season from the file name (`S01E05`), else the parent folder (`2nd Season`, `Season 4 Part 1`), else the directory path so untitled folders stay distinct (Kaguya DB S1 vs Ultra Romantic vs First Kiss). Two groups **overlap** on episode numbers → concatenate spans in walk order, store `1..sum`. Non-overlapping groups are already one axis (Anime Time AoT 01–87 through S04 Part 2) and keep min-max. The isolated `total+1` drop ([#113](113-packfilerange-min-max-skips-extrasova-an-isolated.md)) does not run on a flattened span: Ultra Romantic's 13 is that season's last episode.

Measured packs: Kaguya EMBER 1355132 → 24; Kaguya DB 1928670 → 41 (12+12+13+ the First Kiss 01–04 residue); AoT EMBER 1421679 → 75 (25+12+22+16); Mushoku Anime Time 2169474 → 47 (23+24, `S01E17.5` and `S02E00` skipped).

**Organize does not call AniList.** `SeriesOffset` and `AnimeSeason` are persisted on `EpisodeStruct` from data the pass already computed. `FilesInPackWindow` rebuilds the same groups from the on-disk paths and keeps files whose axis number is in `(offset, offset+total]`. A continuous 1–23 under cour 1 (offset 0, total 11) keeps 01–11 because a contiguous run past the total is the next cour; cour 2 (offset 11) maps 12–23 onto E01–E12. Claimed extras (OVA / `.5` / `S00E` / episode 0) stay out of the span ([#113](113-packfilerange-min-max-skips-extrasova-an-isolated.md)) and are still hardlinked with the **raw** name, including extras that sit in a season group of their own (EMBER `S01E24 [OVA]` next to plain `01–23`, `S02E00` next to un-tagged `01–12`). `animeSeason` on the request keeps an extras-only `Sxx` group from leaking into another season's folder. `organizeTorrent` groups the hash's records by `AnimeID` and calls `Organize` once per folder.

**Don't "fix" by:** storing sequel AniList ids at S1 download; putting `Season NN/` inside one franchise folder; using per-folder file **count** as a pack-choice tie-break ([#84](084-a-pack-without-a-range-in-its-name-gets-its.md) still rejects that); calling AniList from `JobOrganize` ([#68](068-pack-numbering-the-offset-is-guessed-from-the.md)); clamping `declaredSpan` at `AnimeTotalEpisodes` (that deletes the 1–24 pack under S1).
